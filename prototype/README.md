# 造物 Creature · 交互原型

可点击的高保真前端原型，用于需求评审、可用性测试和前端开发起点。所有数据为本地模拟，不调用任何真实模型或后端。

技术栈：React 19 + TypeScript + Vite，图标使用 lucide-react，作品图为程序化生成的 SVG 占位图（`src/lib/art.ts`），不依赖外部图片。

## 运行

```bash
cd prototype
npm install
npm run dev          # 本地开发，默认 http://localhost:5173
npm run build        # 类型检查 + 生产构建，输出到 dist/
npm run build:single # 输出单个内联 HTML 到 dist-single/index.html，双击即可离线打开
```

## 页面与可演示的流程

| 页面 | 地址 | 可以试试 |
|---|---|---|
| 发现 | `#explore` | 切换"小造 Agent / 图像 / 视频…"模式后输入一句话回车；点击作品卡片打开详情并"做同款" |
| 图像工作台 | `#studio-image` | 输入提示词看智能路由推荐的模型与理由；切换"省积分 / 最佳质量"；上传参考图；生成后悬停结果可收藏、变体、转视频 |
| 视频工作台 | `#studio-video` | 图生视频选首帧、运镜、时长受模型上限约束、原生音频 ×1.5 积分 |
| 写作工作台 | `#studio-text` | 流式输出；选中一段文字后改写 / 扩写 / 缩写；"分镜表"模板输出结构化表格并可发送到画布 |
| 音频工作台 | `#studio-audio` | 配音（音色、情绪、语速）与配乐 |
| 画布 | `#canvas` | 拖动节点、拖动空白处平移、滚轮缩放；点选节点修改提示词后下游变为"已过期"；右侧让小造生成计划 → 删减步骤 → 确认执行，节点按依赖顺序运行 |
| 资产 | `#assets` | 分类与文件夹、多选批量操作、角色库、品牌套件 |
| 模板市场 | `#templates` | 单步模板进入工作台，工作流模板在画布上展开为节点 |
| 项目 | `#projects` | 项目卡片 |
| 会员与积分 | `#pricing` | 套餐月付 / 年付、积分包、模拟扫码支付到账、积分明细（冻结 → 结算 / 返还） |
| 管理后台 | `#admin` | 模型健康度与路由权重、启停模型、人工复核队列 |

**演示用的特殊输入**：
- 提示词包含"违规"：演示输入审核拦截，不扣积分。
- 提示词包含"失败"：演示生成失败，积分自动返还，可"重试"或"换模型重试"。
- 小造计划预估超过 300 积分时需要二次确认（PRD 4.6 规则）。

## 目录结构

```text
src/
├── main.tsx / App.tsx       # 入口与应用骨架
├── styles/global.css        # 设计令牌（深浅色主题）与全部样式
├── lib/
│   ├── types.ts             # 领域类型
│   ├── models.ts            # 模型清单、积分预估、智能路由（与 PRD 价目一致）
│   ├── store.tsx            # 全局状态：积分账户、任务模拟、资产、流水、通知
│   ├── router.ts            # 基于 hash 的极简路由
│   ├── mock.ts              # 示例数据
│   └── art.ts               # 程序化占位图、波形、二维码
├── components/              # 导航、模型选择器、作品缩略图、弹窗等
└── pages/                   # 各页面
```

## 与正式开发的关系

- 设计令牌、组件划分、页面结构可直接迁移到 `apps/web`（见 [技术架构](../docs/03-architecture.md) 第 4 节）。
- `lib/models.ts` 的 `estimateCredits` 与 `routeModel` 是计费与路由规则的前端示意，正式版由服务端计算，前端只做展示。
- `lib/store.tsx` 中的任务模拟对应正式版的 `POST /generations` + WebSocket 推送（见 [API 设计](../docs/05-api.md)）。
