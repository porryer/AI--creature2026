## 一页摘要

- **定位**：面向中文创作者与中小品牌团队的 Agent 驱动全模态创作平台。说出想法，平台负责规划、生成、修改、交付整套内容。
- **差异化**：一张画布完成全链路 · 创作 Agent「小造」先计划后执行 · 智能模型路由 · 角色 / 品牌一致性中心 · 透明计费（失败全额返还）· 合规内建。
- **不做**：不自研基础大模型，不做本地 WebUI 与模型训练社区，不做通用聊天。
- **技术路线**：React + Vite 前端；NestJS 模块化单体 + Python Worker；Temporal 编排长任务与 Agent；PostgreSQL + pgvector；多供应商模型网关。
- **节奏**：W1–2 准备，W3–10 MVP，W11–18 Beta（画布 + Agent），W19–26 v1.0（漫剧工作流、协作、开放 API）。
