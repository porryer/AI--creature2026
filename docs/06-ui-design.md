# 06 · UI 交互设计规范

> 适用范围：Web 用户端、移动 H5；管理后台沿用令牌，组件密度更高
> 实现：[`apps/web/`](../apps/web/)（令牌定义见 `apps/web/src/styles/global.css`）

## 1. 设计原则

1. **作品是主角**：界面以中性深色为底，色彩让给用户的作品；装饰元素克制。
2. **参数靠近结果**：调参区、结果区、历史区同屏，减少来回跳转。
3. **成本始终可见**：任何会扣积分的按钮都标注消耗，余额常驻顶栏。
4. **状态一眼可辨**：排队、生成中、完成、失败、过期分别有颜色、图标与文字三重编码。
5. **先建议后执行**：Agent 和智能路由给出建议，用户确认后才花积分。

## 2. 视觉语言

### 2.1 色彩："石青石绿"

主色取自中国画矿物颜料：**石绿**（孔雀石）作为主操作色，**石青**（蓝铜矿）作为辅助色，**藤黄**用于积分与金额，**朱砂**用于危险操作。中性色带一点青绿偏色，与主色同源。

默认深色主题（创作类工具的行业习惯，利于看图），同时完整支持浅色主题与跟随系统。

| 令牌 | 用途 | 深色 | 浅色 |
|---|---|---|---|
| `--bg` | 页面底色（墨） | `#0D1211` | `#F2F5F4` |
| `--surface` | 面板、卡片 | `#141B1A` | `#FFFFFF` |
| `--raised` | 输入框、悬浮层 | `#1B2423` | `#F7FAF9` |
| `--hover` | 悬停底色 | `#232E2C` | `#E7EDEB` |
| `--line` | 分割线、边框 | `#2A3534` | `#D9E1DF` |
| `--fg` | 主文字 | `#E8EEEC` | `#0F1716` |
| `--fg-2` | 次要文字 | `#9DAAA7` | `#4D5B58` |
| `--fg-3` | 辅助文字、占位 | `#6C7976` | `#7B8986` |
| `--accent` | 石绿 · 主按钮、选中、进度 | `#4CC9A4` | `#138A6B` |
| `--on-accent` | 主按钮上的文字 | `#06201A` | `#FFFFFF` |
| `--accent-2` | 石青 · 链接、视频类型、连线 | `#6B9BF2` | `#2F5FC4` |
| `--gold` | 藤黄 · 积分、价格 | `#E9B949` | `#A87508` |
| `--danger` | 朱砂 · 删除、失败 | `#EF6A52` | `#C8402B` |
| `--ok` | 成功状态 | `#5CC98A` | `#23854F` |

**模态色**（区分内容类型，用于标签、节点头部、图标）：图像 = 石绿，视频 = 石青，写作 = 藤黄，音频 = 紫藤 `#B48CE8` / `#7A4FC0`。

**对比度**：正文与背景对比度 ≥ 7:1，次要文字 ≥ 4.5:1，主按钮文字 ≥ 4.5:1。

### 2.2 字体

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 展示 | `"Bricolage Grotesque", "Noto Sans SC", "PingFang SC", sans-serif` | 品牌字标、页面大标题、数字 |
| 正文 | `"Noto Sans SC", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif` | 界面文字 |
| 等宽 | `"JetBrains Mono", "SFMono-Regular", Menlo, monospace` | 积分数值、参数、种子、ID |

**字号阶梯**（px）：12 · 13 · 14（正文）· 16 · 20 · 24 · 32 · 44。行高：正文 1.6，标题 1.25。

### 2.3 间距、圆角、阴影

- 间距基数 4 px：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 圆角：输入与按钮 8 px；卡片 12 px；大面板 16 px；标签全圆角。
- 阴影只用于浮层（下拉、弹窗、Toast），卡片用边框区分层级。

### 2.4 图标

线性图标，1.75 px 描边，24 px 栅格（原型使用 lucide 图标集）。

## 3. 全局布局

```text
┌──────┬──────────────────────────────────────────────────────┐
│      │  顶栏：页面标题 · 搜索 · 积分余额 · 通知 · 头像       │
│ 导航 ├──────────────────────────────────────────────────────┤
│  轨  │                                                      │
│ 72px │                 主工作区（按页面变化）                │
│      │                                                      │
└──────┴──────────────────────────────────────────────────────┘
```

- **导航轨**：发现、创作、画布、资产、模板、项目；底部为会员、后台入口与主题切换。
- **移动端（< 768 px）**：导航轨变为底部标签栏（5 个主入口），顶栏精简为标题 + 积分。

**断点**：`sm < 768` · `md 768–1199` · `lg ≥ 1200`。

## 4. 页面规范

### 4.1 发现页（首页）

```text
┌───────────────────────────────────────────────┐
│  今天想造点什么？                              │
│  ┌─────────────────────────────────────────┐  │
│  │ 描述你的创意……                    [生成] │  │
│  └─────────────────────────────────────────┘  │
│  [小造 Agent] [图像] [视频] [写作] [音频]      │
├───────────────────────────────────────────────┤
│  热门模板  ← 横向滚动卡片 →                    │
├───────────────────────────────────────────────┤
│  灵感广场  [推荐|最新|最热]  [全部|图像|视频]  │
│  ┌──┐┌────┐┌──┐┌───┐                           │
│  │  ││    ││  ││   │   瀑布流                   │
│  └──┘│    │└──┘│   │                           │
└───────────────────────────────────────────────┘
```

### 4.2 创作工作台

```text
┌─────────────┬───────────────────────────────┬────────────┐
│ 模式切换     │  任务卡片（最新在上）          │ 历史记录    │
│ 提示词       │  ┌ 提示词摘要 · 模型 · 积分 ┐  │ 缩略图列表  │
│ 模型（自动） │  │ ▓▓▓▓▓▓░░░░ 生成中 62%    │  │            │
│ 参考图       │  └──────────────────────────┘  │            │
│ 比例 / 数量  │  ┌──┐┌──┐┌──┐┌──┐ 结果网格     │            │
│ 高级选项     │  └──┘└──┘└──┘└──┘              │            │
│ [生成 · 24 积分]│                             │            │
└─────────────┴───────────────────────────────┴────────────┘
   320px                 自适应                     240px
```

- 生成按钮固定在参数面板底部，文案始终包含积分消耗；余额不足时变为"积分不足，去充值"。
- 结果卡悬停出现操作条：下载、收藏、变体、局部重绘、转视频、加入画布。
- `md` 断点隐藏历史栏（改为顶部按钮打开抽屉）；`sm` 断点参数面板折叠为底部抽屉。

### 4.3 画布

```text
┌───────────────────────────────────────────────┬──────────────┐
│ 工具条：选择 · 新增节点 · 运行全部 · 缩放      │  小造 Agent   │
│                                               │  对话消息     │
│   [文本]──────►[图像生成]──────►[视频生成]      │  计划卡片     │
│                    │                          │  ┌ 步骤 ×4 ┐ │
│                    └──────►[图像编辑]          │  │ 260 积分 │ │
│                                               │  └ [确认执行]┘│
│                                     [小地图]   │  输入框       │
└───────────────────────────────────────────────┴──────────────┘
```

- 节点头部用模态色标识类型；输入口在左、输出口在右；连线颜色继承上游节点的模态色。
- 节点状态在头部右侧显示圆点 + 文字；运行中节点边框显示流动进度。
- Agent 面板可收起；移动端以全屏抽屉打开。

### 4.4 资产中心

左侧分类（全部 / 图像 / 视频 / 音频 / 文本 / 角色 / 品牌套件 / 文件夹），右侧网格；支持多选批量操作（移动、下载、删除、加入画布）。

### 4.5 模板市场

分类筛选 + 卡片网格。卡片包含封面、标题、"单步 / 工作流"标签、步骤数、预计积分、使用次数。点击打开详情抽屉，主按钮为"使用模板"。

### 4.6 会员与积分

套餐卡片横排（移动端纵向），推荐档位以石绿描边标识；下方为积分余额（可用 / 冻结 / 即将过期）、近 30 天消耗图与积分明细表。

## 5. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 石绿底 + `--on-accent` 文字，高 40 px；含积分时右侧以等宽字显示"· 24 积分" |
| 次按钮 | `--raised` 底 + `--line` 边框 |
| 幽灵按钮 | 透明底，悬停 `--hover` |
| 危险按钮 | 朱砂文字，二次确认在页面内完成（不用浏览器弹窗） |
| 分段控件 | 用于比例、数量、模式切换；选中项石绿底 |
| 模型选择器 | 下拉卡片：模型名、供应商、质量 / 速度星级、单价、标签（推荐 / 新 / 含音频） |
| 积分徽章 | 藤黄色硬币图标 + 等宽数字 |
| 任务进度条 | 高 4 px，石绿填充；排队时显示"前方 N 个任务" |
| 状态标签 | 排队（灰）· 生成中（石青 + 动效）· 完成（绿）· 失败（朱砂）· 已过期（藤黄） |
| Toast | 右下角（移动端在底部标签栏上方），普通提示 3 秒、失败提示 6 秒后自动消失，均可手动关闭；失败信息同时保留在任务卡与通知中心 |
| 空状态 | 说明会出现什么内容 + 一个明确的下一步按钮 |

## 6. 交互细节

- **快捷键**：`Enter` 提交（`Shift+Enter` 换行）；`/` 聚焦提示词；画布中 `Space` 拖拽、`Cmd/Ctrl + Enter` 运行选中节点、`Delete` 删除节点。
- **长任务**：提交后立即显示任务卡与排队位置；用户离开页面后完成，在通知中心与浏览器通知提醒。
- **失败处理**：任务卡显示失败原因（人话）与"已返还 N 积分"，提供"重试"与"换模型重试"。
- **审核拦截**：提示"内容可能违反社区规范，未生成，积分已返还"，不暴露具体敏感词。
- **AI 标识**：所有结果缩略图右下角显示小号"AI 生成"角标（与交付文件中的显式标识一致）。
- **动效**：时长 150–250 ms，缓动 `cubic-bezier(.2,.8,.2,1)`；尊重 `prefers-reduced-motion`，关闭非必要动效。

## 7. 可访问性

- 所有交互元素可通过键盘访问，焦点环 2 px 石绿外描边。
- 图标按钮必须有 `aria-label`；状态变化通过 `aria-live` 播报（如"生成完成"）。
- 不只用颜色传达状态，配合图标与文字。
