# 造物 Creature · 用户端

React 19 + TypeScript + Vite，图标使用 lucide-react。由最初的交互原型演进而来，同一套界面支持两种模式：

| 模式 | 启动方式 | 数据来源 |
|---|---|---|
| 离线演示（mock） | `npm run dev` / `npm run build:demo` | 本地模拟：任务进度按时间模拟，作品为程序化生成的占位图 |
| 接入后端（api） | `npm run dev:api`（或在仓库根目录 `npm run dev`） | `apps/server` 提供的 `/v1` 接口与服务端推送 |

模式由 `VITE_BACKEND` 决定（`api` / `mock`，默认 mock）。开发服务器把 `/v1` 代理到 `http://localhost:3000`，可用 `API_TARGET` 修改。

## 命令

```bash
npm run dev          # 离线演示模式
npm run dev:api      # 接入后端（需先启动 apps/server）
npm run build        # 生产构建（api 模式），输出 dist/
npm run build:demo   # 单文件离线演示版，输出 dist-single/index.html，双击即可打开
npm run typecheck
```

## 页面与可演示的流程

| 页面 | 地址 | 可以试试 |
|---|---|---|
| 登录（api 模式） | — | 手机号 + 验证码；开发环境验证码自动填入 |
| 发现 | `#explore` | 切换"小造 Agent / 图像 / 视频…"模式后输入一句话回车；灵感广场推荐 / 最新 / 最热 / 我的发布，作品详情可喜欢、做同款（沿用原作参数与模型）、举报，自己的作品可撤回 |
| 图像工作台 | `#studio-image` | 智能路由推荐与理由；上传或从资产库选择参考图，点角标切换用途（风格 / 主体 / 角色）；结果可收藏、变体、转视频；排队中的任务可取消 |
| 视频工作台 | `#studio-video` | 图生视频 / 首尾帧（从资产库选择或上传）、运镜、时长受模型上限约束、原生音频 ×1.5 积分 |
| 写作工作台 | `#studio-text` | 逐段输出；选中文字后改写 / 扩写 / 缩写；分镜表输出结构化表格 |
| 音频工作台 | `#studio-audio` | 配音与配乐；api 模式下播放后端生成的 WAV（开头带 AI 提示音） |
| 画布 | `#canvas` | 拖动节点、平移缩放；小造生成计划 → 删减步骤 → 确认执行，节点按依赖顺序运行；接入后端时自动保存（左下角显示保存状态，可直接改名） |
| 资产 | `#assets` | 分类、搜索、文件夹（新建 / 重命名 / 删除）、多选批量移动 / 下载 / 删除、上传素材（PNG / JPEG / WebP，上传素材不带 AI 标识）、作品详情里发布到广场、角色库、品牌套件 |
| 模板市场 | `#templates` | 单步模板进入工作台，工作流模板在画布上展开为节点（接入后端时生成一个新项目） |
| 项目 | `#projects` | 接入后端时列出项目，可新建、打开对应画布、删除 |
| 会员与积分 | `#pricing` | 套餐与积分包、模拟支付到账、积分明细（冻结 → 结算 / 返还） |
| 管理后台 | `#admin` | 接入后端时仅管理员可见：运营概览、模型健康度、广场复核队列（通过 / 下架）；离线演示为示例数据 |

**演示用的特殊输入**（两种模式都支持）：
- 提示词包含"违规"：输入审核拦截，不扣积分。
- 提示词包含"失败"：生成失败，积分自动返还，可"重试"或"换模型重试"。
- 提示词包含"超时"（api 模式）：主模型超时，自动切换备选模型完成。
- 提示词包含"敏感画面"（api 模式）：输出审核拦截并返还。
- 小造计划预估超过 300 积分时需要二次确认。

## 目录结构

```text
src/
├── main.tsx / App.tsx       # 入口；api 模式下按登录态显示登录页或工作区
├── styles/global.css        # 设计令牌（深浅色主题）与全部样式
├── lib/
│   ├── api.ts               # 接口客户端：内存访问令牌、Cookie 刷新令牌、401 自动刷新、SSE 重连
│   ├── store.tsx            # 全局状态：两种模式共用同一接口（submit / purchase / login …）
│   ├── types.ts             # 前端领域类型（基础类型来自 @creature/shared）
│   ├── router.ts            # 基于 hash 的极简路由
│   └── mock.ts              # 离线演示数据（灵感广场、模板、项目、后台等）
├── components/              # 导航、模型选择器、作品缩略图、弹窗等
└── pages/                   # 各页面
```

模型目录、积分计价、智能路由与占位作品生成都来自 `packages/shared`，与后端是同一份实现，因此界面上显示的积分预估与后端实际冻结的积分一致。

## 尚未接入后端的部分

模板市场、角色库与品牌套件仍使用示例数据；离线演示模式下灵感广场与管理后台也是示例数据。接入后端时，项目与画布保存在服务端（打开画布默认进入最近编辑的一个）；离线演示模式下画布不保存。多人协作在 Beta 版本实现。
