# 造物 Creature

面向中文创作者与中小品牌团队的 **Agent 驱动 AI 全模态创作平台**：在一张无限画布上，用一句话完成文案、图像、视频、配音的整套内容生产。

## 仓库内容

| 目录 | 内容 |
|---|---|
| [`docs/`](./docs/) | 竞品调研、PRD、技术架构、数据库、API、UI 规范、开发计划、合规方案 |
| [`prototype/`](./prototype/) | React + TypeScript 可交互原型（本地模拟数据） |

## 快速开始

```bash
cd prototype
npm install
npm run dev
```
